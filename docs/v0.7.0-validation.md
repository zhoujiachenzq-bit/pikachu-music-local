# v0.7.0 验收记录

日期：2026-11-02。范围：Claude 前端打磨的收尾，以及 v0.6.12 后尚未提交的发现目录与 Android WebView 兼容修复。本轮按用户要求修改、测试并提交 v0.7.0；不包含云部署。

## 实现结果

- 六主题保留；稳定指针区域驱动唱片倾斜，倾斜和旋转分层，暂停保留角度。增加局部高光、按压和弹窗退出反馈；关闭动态及减少动态有静态路径。
- 推荐歌单拖动时暂时取消吸附，避免回跳。发现弹窗打开后自动加载推荐，侧栏自建歌单卡改为整行。
- 花园换用 moon-gate-garden.webp，并加入 Service Worker 静态缓存；保留已有主题 ID、用户偏好及原有背景素材。
- 收尾改善街机、海岸长歌名两行展示和 320px 街机、钴蓝播放卡间距。保留“暮光花园”名称，未擅自改名。
- 修复歌词历史标记在刷新后阻止展开的问题。
- 网易云公开发现目录可独立于 Go 服务读取，失败保留备用通道；旧 WebView 不再依赖缺失的 AbortSignal 方法。Windows 仅在已有本地 helper 时按需隐藏启动，不下载程序。
- package、Android versionName、PWA 缓存统一 0.7.0；versionCode 为 73。应用 ID、存储和固定签名配置未变。

浏览器主题切换需等待过渡层结束再测量，避免将过渡中间态当成最终主题。上述矩阵在每次切换完成后采集。使用固定合成歌曲，不代表真实平台听感、真实封面或上游长期可用性。
