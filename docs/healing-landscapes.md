# 治愈风景主题

主题选择器第一组为经典设计（剪纸画室、霓虹游戏厅、钴蓝画廊），第二组为治愈风景（夏日海岸、晴空花野、暮光花园）。保留 night / vinyl / burgundy 内部 ID，兼容账户偏好。

夏日海岸与晴空花野使用内置 imagegen 生成的原创插画，文件为 public/summer-coast.png 与 public/sunny-meadow.png。分别以夏日海滩、春日花野为构图，天空留白、远景山丘、中景海岸或风车、前景植物形成画面景深。两者采用浅色控件和深色文字；暮光花园保持暮色配色。环境动画不移动镜头，手机和减少动态模式关闭循环。

已通过 43 个测试文件共 224 项测试、类型检查、生产构建。浏览器检查 1146×986 两个主题播放器和 390×844 花野聊天输入区；分类顺序已检查。使用本地静音夹具，未发布或部署。构建保留 Three.js 大分块提示。
