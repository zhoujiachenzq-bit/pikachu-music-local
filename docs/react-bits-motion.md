## 本地验收

使用 `scripts/motion-ui-fixture.ts`：仅监听回环地址，内存账户和歌单，合成静音音频，不使用线上数据或真实模型。

- 收藏、加入歌单成功后观察到局部火花；预设失败返回错误且无成功火花。键盘 Enter 收藏也有反馈。
- 在播放器、每日推荐、珍奇及设置之间切换，单一音乐 audio 保持播放，进度继续推进。
- 精选封面和唱片的高光响应指针，过渡 700ms；390px 手机布局高光关闭，精选封面和图片均为 68px。
- 夜幕、钴蓝边缘画布初始化成功，无 WebGL 渲染错误；关闭动态场景后画布移除，手机不创建边缘画布。
- 390px、1280px、1920px、2048px 视口检查未出现横向页面溢出。珍奇输入前后边界一致，点击输入框的水波和火花数量均为 0。
- `pnpm test`：43 个测试文件、224 项通过；`pnpm typecheck`、`pnpm build`、`git diff --check` 均退出 0。构建仍有既有 Three.js 大分块提示，没有新增动画依赖。

上述为桌面浏览器响应式验收，不等于真机手机或系统减少动态实测；后者已接入媒体查询，但本轮未切换操作系统设置验证。未进行长时间 GPU/低端设备性能基准，也未验收真实音源听感或模型回复。

## Grainient：四处接入（2026-09-04）

使用用户提供的官方提示与着色器，复用 Three.js，没有增加 OGL 依赖。新增 `Grainient.tsx` 与 `grainientShader.ts`。

- 酒红剧场：播放器和珍奇共用中栏渐变，暗玫瑰、深酒红、少量暖金；替换原有中栏 WebGL，歌词与聊天仍有稳定底色。
- 每日推荐：顶部展示区按六主题配色；展示推荐时不叠加原中栏场景。浅色主题补齐小标题、按钮和唱片店精选卡的对比度。
- 纸上唱片店：全视口奶油/砖红颗粒渐变，替换原有中栏动态场景以控制同时运行的画布数量；保留两侧装饰、主题布局和皮卡丘素材。
- 登录/注册：深蓝暖金背景替换原网格和光团；表单保持深色独立底层。背景动效开关单独保存在本机，不影响账户配置。

速度 .045–.075、静态颗粒、桌面最高 24fps/手机最高 18fps、画布最高 1280×900；离屏/后台暂停，关闭动效或系统减少动态时不创建 WebGL，保留静态渐变。释放观察器、帧循环与 GPU 资源，WebGL 失败回退静态背景。

实测登录/推荐/唱片店/酒红中栏画布初始化成功，切换主题与进入珍奇时单一音频继续播放。390px 手机与 1280px 桌面查看画面，1920px 宽屏检查全视口背景，无横向溢出。点击珍奇输入框无水波；全局关闭动态以及登录页独立关闭后 Grainient canvas 数量均为 0。最终 224 项测试、类型检查与构建通过；真机/GPU 长时基准仍未进行。未提交、推送或部署。

上述为第一阶段记录。ElasticSlider、GlassIcons、CardNav、MetallicPaint、TiltedCard 已在下面的第二阶段接入；FlowingMenu 仍不加入。
